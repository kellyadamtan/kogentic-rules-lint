# F006 unreachable-rule

Default severity: **warning**

## What it flags

A Cursor rule with `alwaysApply: false` (or missing), no `globs` and no `description`.

## Why it matters

Cursor only loads it when someone @-mentions it by name, which is usually a mistake.

## Bad

```yaml
---
alwaysApply: false
---
```

## Good

```yaml
---
description: How to write database migrations
alwaysApply: false
---
```

## How to fix

Add `globs` to auto-attach it, a `description` so the agent can choose it, or `alwaysApply: true`.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  F006: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line F006 -->`.
