# S004 glob-matches-nothing

Default severity: **warning**

## What it flags

A `globs` (Cursor, Windsurf), `paths` (Claude Code) or `applyTo` (Copilot) pattern that matches no file in the repo (files ignored by .gitignore do not count). Invalid glob syntax is reported too.

## Why it matters

A rule whose glob matches nothing never loads. This usually means a typo or a renamed folder.

## Bad

```yaml
---
globs: src/componets/**/*.tsx
---
```

## Good

```yaml
---
globs: src/components/**/*.tsx
---
```

## How to fix

Patterns are relative to the repo root. A pattern without a slash (like `*.tsx`) is also tried against file names.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  S004: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line S004 -->`.
