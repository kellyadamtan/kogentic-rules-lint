# C003 drift-between-tools

Default severity: **error**

## What it flags

A CLAUDE.md-family file (CLAUDE.md, CLAUDE.local.md, .claude/..., imports) and an AGENTS.md or Copilot instructions file disagree on the same subject (same table as C002).

## Why it matters

Different agents get different rules for the same repo.

## Bad

CLAUDE.md: `Use 2 spaces.` AGENTS.md: `Use tabs.`

## Good

AGENTS.md holds the rule; CLAUDE.md contains `@AGENTS.md`.

## How to fix

Keep one source of truth (for example AGENTS.md) and import it from CLAUDE.md with `@AGENTS.md`, or symlink one file to the other.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  C003: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line C003 -->`.
