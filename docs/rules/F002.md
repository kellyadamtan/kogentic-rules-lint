# F002 bad-frontmatter

Default severity: **error**

## What it flags

Rule frontmatter that is not valid YAML, has unknown keys, or has values of the wrong type (`alwaysApply` must be a boolean, `globs`/`paths` a string or list, `applyTo`/`description` strings, Windsurf `trigger` one of `always_on`, `manual`, `model_decision`, `glob`). Checked for Cursor `.mdc`, Claude `.claude/rules`, Copilot `.instructions.md` and Windsurf `.windsurf/rules` files.

## Why it matters

Tools ignore broken or misspelled frontmatter, so the rule loads at the wrong time or never.

## Bad

```yaml
---
alwaysApply: "yes"
glob: src/**
---
```

## Good

```yaml
---
alwaysApply: false
globs: src/**
---
```

## How to fix

Unquoted Cursor/Windsurf globs such as `globs: *.tsx` are accepted (the tools allow them even though they are not strict YAML). Keys that belong to another vendor are reported by F003 instead.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  F002: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line F002 -->`.
