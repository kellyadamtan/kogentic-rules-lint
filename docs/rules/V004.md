# V004 hedged-rule

Default severity: **warning**

## What it flags

Hedges like "try to", "if possible", "ideally", "preferably" on something that reads like a rule.

## Why it matters

A hedge tells the agent the rule is optional, so under pressure it skips it.

## Bad

- Try to keep functions under 50 lines.
- Ideally, run the tests.

## Good

- Keep functions under 50 lines; split longer ones.
- Run `make test` before you finish.

## How to fix

Decide: make it a hard rule (and maybe a hook, see `kogentic-rules-lint harden`), or say plainly that it is optional and when.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  V004: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line V004 -->`.
