# F004 missing-applyTo

Default severity: **error**

## What it flags

A Copilot `.github/instructions/**/*.instructions.md` file without `applyTo`.

## Why it matters

Without `applyTo`, Copilot does not apply the file automatically.

## Bad

```yaml
---
description: API conventions
---
```

## Good

```yaml
---
applyTo: "src/api/**/*.ts"
---
```

## How to fix

Add `applyTo` (use `"**"` for every file).

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  F004: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line F004 -->`.
