# V002 generic-filler

Default severity: **info**

## What it flags

Instructions every coding agent already follows: "be helpful", "write high-quality code", "think step by step", "you are an expert", "don't hallucinate".

## Why it matters

They add tokens to every session and change nothing.

## Bad

- You are an expert engineer. Be helpful and accurate.
- Think step by step.

## Good

- Prefer small pull requests: one feature or fix per branch.

## How to fix

Delete it, or replace it with something specific to this project.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  V002: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line V002 -->`.
