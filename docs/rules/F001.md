# F001 mdc-extension

Default severity: **error**

## What it flags

A `.md` file inside `.cursor/rules/`.

## Why it matters

Cursor only loads `.mdc` files from `.cursor/rules/`, so the file is silently ignored.

## Bad

`.cursor/rules/testing.md`

## Good

`.cursor/rules/testing.mdc` with `description`, `globs` and `alwaysApply` frontmatter.

## How to fix

Rename the file to `.mdc` and add frontmatter.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  F001: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line F001 -->`.
