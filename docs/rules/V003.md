# V003 unbounded-quantifier

Default severity: **warning**

## What it flags

"always" or "never" with no scope: no condition (when/if/before/in/for...), path or glob.

## Why it matters

Unscoped absolutes are often wrong somewhere (generated code, tests, scripts), so agents learn to treat them as soft.

## Bad

- Never use any.
- Always add comments.

## Good

- Never use `any` in `src/**/*.ts`; tests may use it.
- Always add a doc comment when you export a function.

## How to fix

Add the condition or glob, or keep it if it truly applies everywhere and disable the finding inline. Warning only.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  V003: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line V003 -->`.
