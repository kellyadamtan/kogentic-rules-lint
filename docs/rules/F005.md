# F005 dead-reference

Default severity: **warning**

## What it flags

An `@path` import in CLAUDE.md that points to a missing file, or a backticked repo path (with a slash, no globs or placeholders) that does not exist.

## Why it matters

Dead imports load nothing, and stale paths send the agent looking for files that are gone.

## Bad

- See @docs/old-guide.md
- Shared helpers live in `src/utils/helpers.ts` (file was renamed).

## Good

- See @docs/guide.md
- Shared helpers live in `src/lib/helpers.ts`.

## How to fix

Imports resolve relative to the importing file. Paths are checked relative to the repo root and to the file's folder. `~/` and absolute imports are not checked.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  F005: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line F005 -->`.
