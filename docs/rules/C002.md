# C002 contradiction

Default severity: **error**

## What it flags

Opposite directives on the same subject, from a fixed subject table: package manager (npm/pnpm/yarn/bun), indentation (tabs/N spaces), quotes (single/double), test runner (jest/vitest/mocha/pytest/unittest), language (TypeScript/JavaScript), plus "always X" vs "never X" with the same X. Deterministic, no LLM.

## Why it matters

When rules disagree, the agent picks one at random, and it may not be the one you meant.

## Bad

- Use pnpm for all scripts.
- Use npm to install packages.

## Good

- Use pnpm for installing packages and running scripts.

## How to fix

Keep one directive, or scope each to where it applies. Pairs of CLAUDE.md vs AGENTS.md/Copilot files are reported as C003.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  C002: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line C002 -->`.
