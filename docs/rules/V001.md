# V001 vague-instruction

Default severity: **warning**

## What it flags

An instruction with no checkable criterion: "make it more X like", "clean/nice/better/proper/good", "be careful", "as needed", "where appropriate", "best practices", or a list that ends in "etc.".

## Why it matters

The agent cannot tell when it has followed a vague instruction, so it guesses, and you end up correcting the same thing again.

## Bad

- Write clean code.
- Handle errors properly.
- Use the usual tools: eslint, prettier, etc.

## Good

- When a function returns an error, wrap it with `fmt.Errorf("...: %w", err)`; verify by `go vet ./...`.
- Run `npm run lint` and fix every warning before you finish.

## How to fix

Rewrite it as **When &lt;situation&gt;, do &lt;action&gt;; verify by &lt;check&gt;**. Instructions that already contain code, a number, an example ("e.g.", "such as") or an explicit check are not flagged.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  V001: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line V001 -->`.
