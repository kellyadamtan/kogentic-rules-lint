# S003 too-long

Default severity: **warning**

## What it flags

A Cursor rule over 500 lines, or a Windsurf workspace rule (`.windsurf/rules/*.md`, `.windsurfrules`) over about 12,000 characters.

## Why it matters

Vendors recommend these limits; Windsurf truncates longer rules.

## Bad

A 900-line `.cursor/rules/everything.mdc`.

## Good

Several focused `.mdc` files, each with its own `globs`.

## How to fix

Split the file into smaller scoped rules.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  S003: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line S003 -->`.
