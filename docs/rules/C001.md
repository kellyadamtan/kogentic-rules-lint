# C001 duplicate

Default severity: **warning**

## What it flags

Near-duplicate instructions within one file or across files (normalized text, word-bigram Jaccard similarity of 0.85 or more; instructions under four words are skipped).

## Why it matters

Copies drift apart over time and then contradict each other; they also cost tokens twice.

## Bad

CLAUDE.md: `- Run the full test suite before every commit.`
AGENTS.md: `- Run the full test suite before every commit!`

## Good

Keep it in AGENTS.md and add `@AGENTS.md` to CLAUDE.md.

## How to fix

The finding is reported on the later copy and names the earlier one to keep.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  C001: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line C001 -->`.
