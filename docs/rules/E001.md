# E001 should-be-hook

Default severity: **info**

## What it flags

A hard rule that a hook or test could check mechanically: a path deny-list ("never edit `dist/`"), a command deny-list ("don't run `rm -rf`"), a secret-file rule ("never commit .env"), "every change to X needs a test", or "always run `cmd` before committing".

## Why it matters

An agent can ignore a sentence; it cannot ignore a hook that blocks the tool call.

## Bad

- Never edit files in `dist/`.

## Good

Keep the sentence and run:

```sh
kogentic-rules-lint harden "Never edit files in dist/" --as hook --write
```

## How to fix

The finding prints the exact `harden` command. See the README for the templates.

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  E001: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line E001 -->`.
