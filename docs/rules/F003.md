# F003 cross-vendor-frontmatter

Default severity: **warning**

## What it flags

A frontmatter key from another tool (for example Cursor's `alwaysApply` in a Windsurf or Copilot file, or `applyTo` in a Cursor rule), or a Windsurf rule without `trigger`.

## Why it matters

Each tool reads only its own keys; the others are ignored, so the file is not scoped the way you think.

## Bad

`.windsurf/rules/api.md`:

```yaml
---
alwaysApply: true
---
```

## Good

```yaml
---
trigger: always_on
---
```

## How to fix

Use the tool's own key: `globs`/`alwaysApply` (Cursor), `paths` (Claude Code), `applyTo` (Copilot), `trigger`/`globs` (Windsurf).

## Turn it off

In `.kogentic-rules-lint.yaml`:

```yaml
rules:
  F003: off
```

Or inline, for one line: `<!-- rules-lint-disable-next-line F003 -->`.
